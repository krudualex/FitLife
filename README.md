# FitLife — платформа для спорту та здорового способу життя

**FitLife** — адаптивний двомовний (українська/англійські елементи інтерфейсу) демонстраційний сайт для портфоліо. Створений на HTML, CSS і JavaScript без збірки та без обов’язкового сервера.

## Сторінки

- `index.html` — головна сторінка.
- `workouts.html` — каталог тренувань із пошуком і фільтрами.
- `nutrition.html` — калькулятор ІМТ, оцінка добової потреби в калоріях і приклад меню.
- `blog.html` — короткі статті про звички, харчування та відновлення.
- `contact.html` — демонстраційна форма контактів; повідомлення автоматично не надсилаються.
- `account.html` — демонстраційний кабінет зі звичками, які зберігаються в локальному сховищі браузера.
- `styles.css` — стилі, адаптивність та анімації.
- `script.js` — мобільна навігація, фільтри та анімації.

## Запуск локально

1. Завантажте ZIP-архів і розпакуйте його.
2. Відкрийте папку `fitlife`.
3. Відкрийте `index.html` у сучасному браузері.

Для комфортної локальної перевірки можна використати розширення **Live Server** у Visual Studio Code. Збірка або встановлення залежностей не потрібні.

## Публікація через GitHub Pages

1. Увійдіть у GitHub і створіть новий репозиторій, наприклад `fitlife`.
2. Завантажте в корінь репозиторію всі файли з цієї папки: HTML-файли, `styles.css`, `script.js`, `README.md` та папку `assets`, якщо вона є.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть **Deploy from a branch**.
5. Вкажіть гілку `main` і папку `/ (root)`, потім натисніть **Save**.
6. Дочекайтеся завершення публікації. Адреса сайту з’явиться в розділі Pages.

Якщо репозиторій називається `username.github.io`, сайт буде опубліковано на кореневій адресі користувача. Для звичайного репозиторію адреса зазвичай має формат `https://username.github.io/fitlife/`.
